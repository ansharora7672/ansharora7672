## Projects

**TalentHeads** - Enterprise AI hiring platform. 7-agent LangGraph pipeline populating
a Neo4j knowledge graph across a 7-layer LinkedIn V2 taxonomy with Dreyfus-scored
competency rubrics, cross-provider LLM fallback chain, and a two-stage candidate
ranking pipeline using BAAI/bge-large-en-v1.5 embeddings.
- Stack: LangGraph, Neo4j, GraphRAG, FastAPI, PostgreSQL, Redis, Keycloak, Oracle Cloud

**AppliOS** - Autonomous job discovery platform scraping 78 companies across 7 native
ATS APIs with deterministic MD5 deduplication, 5-provider LLM fallback chain,
autonomous LaTeX repair loop, and a 23-table PostgreSQL schema tracking the full
application lifecycle.
[Watch demo](https://youtu.be/kVOpe5jnkdI)
- Stack: FastAPI, LangChain, PostgreSQL, React 19, SSE, Docker Compose

**E.T.H.O.S** - End-to-end ML pipeline classifying 9,500+ NASA Kepler exoplanet
candidates. Random Forest achieving 94.91% accuracy with physics-constrained data
auditing, MLflow experiment tracking, and staged model promotion to production.
[Live system](https://eth0s.online/)
- Stack: Scikit-learn, MLflow, FastAPI, Streamlit, AWS EC2, Docker

**SmartFab Lathe** - Full Quote-to-Cash platform built solo from vague client
requirements to production. Blue-green AWS deployment, full CI/CD, OAuth2 auth,
Playwright-based PDF generation pipeline.
[smartfablathe.com](https://smartfablathe.com/)
